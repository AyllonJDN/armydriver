# Radar 360° — Army Driver

Sitio de una sola página (HTML/CSS/JS estático, sin build) que presenta el reporte de investigación de
**StelUp Agency** sobre el prospecto Army Driver (Fase 0).

## Contenido
- Resumen ejecutivo
- Reunión de descubrimiento (05-nov-2026)
- Redes sociales (Instagram, Facebook, TikTok) con capturas, copys y métricas reales
- Cobertura de prensa
- Análisis de contenido, diseño y estructura del sitio web del prospecto
- Recomendaciones

## Despliegue
Sitio 100% estático — no requiere build ni dependencias. Se despliega directamente en Vercel importando este
repositorio (Framework Preset: **Other / Static**).

## Estructura
```
index.html     Página principal
styles.css     Estilos (sistema de diseño StelUp Agency)
script.js      Tabs, acordeón, lightbox, menú móvil, animaciones de scroll
img/           Capturas de pantalla (Instagram, Facebook, TikTok, prensa, sitio web)
```

Documento de uso interno — confidencial.
